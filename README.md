간편한 주문과 결제를 통해 소중한 사람에게 선물을 전달할 수 있도록
사용자 편의성과 고급스러운 쇼핑 경험에 중점을 두었습니다.

## 🎁 프로젝트 소개

### "마음을 담은 선물, Maison De SAJO"

Maison De SAJO는 다양한 상황과 대상에 맞는
선물세트를 편리하게 선택하고 구매할 수 있는
온라인 선물 쇼핑몰입니다.

생일, 건강, 출산·돌, 결혼·집들이 등 다양한 선물 상황을
카테고리별로 구성하여 원하는 상품을 쉽게 찾을 수 있도록 하였으며,

상품 조회부터 찜, 장바구니, 주문 및 결제,
리뷰 작성까지 이어지는 쇼핑 과정을 하나의 웹사이트에서
편리하게 이용할 수 있도록 구현하는 것을 목표로 합니다.


## ✨ 주요 기능

### 👤 회원
- 회원가입
- 아이디 중복 확인
- 로그인 / 로그아웃
- 회원정보 조회 및 수정
- 회원 등급 관리
- 포인트 및 쿠폰 조회

### 🛍️ 상품
- 상품 목록 조회
- 상품 상세 조회
- 카테고리별 상품 조회
- 상품 옵션 선택
- 상품 수량 선택
- 상품 가격 및 할인율 표시

### ❤️ 쇼핑
- 상품 찜
- 장바구니
- 주문 및 결제
- 배송지 등록
- 배송지 관리

### ⭐ 리뷰
- 리뷰 조회
- 리뷰 작성
- 리뷰 관리

### 👨‍💼 관리자
- 상품 등록
- 주문 및 배송 관리
- 쿠폰 등록 / 조회 / 삭제

## 🎨 UI / UX
Maison De SAJO는 **프리미엄 선물세트 쇼핑몰**이라는 컨셉에 맞춰
깔끔하고 직관적인 UI를 목표로 디자인하였습니다.

카카오톡 선물하기와 다양한 온라인 쇼핑몰의
사용자 경험을 참고하여 상품 탐색부터 결제까지
쉽게 이용할 수 있는 화면 구성을 설계하였습니다.


## 📌 프로젝트 목표
단순한 상품 판매 사이트가 아닌,

**"선물을 고르는 과정 자체가 편리하고 즐거운 쇼핑 경험"**

을 제공하는 것을 목표로 합니다.

사용자는 원하는 상황과 카테고리에 맞는 선물을 쉽게 찾고,
관리자는 상품, 주문, 쿠폰 등의 데이터를 효율적으로 관리할 수 있도록
사용자와 관리자 페이지를 분리하여 구성하였습니다.
